# Changelog

## [0.1.0] - 2026-08-11

Initial public MVP of `x-knowledge-inbox`.

- Added local SQLite inbox for user-selected X bookmark imports.
- Added JSON, JSONL, and CSV import with URL deduplication.
- Added search, tags, review states, weekly digest, and Markdown/JSON/CSV export.
- Added a dependency-free local web view.
- Added tests, demo data, security policy, and contribution guidance.
